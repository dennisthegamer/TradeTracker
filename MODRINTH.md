# TradeTracker

**Track every trade. Know every profit. Master the emerald economy!**

TradeTracker is a client-side mod for **Fabric and NeoForge** that automatically tracks and analyzes all your Villager and Wandering Trader trades, calculating emerald profit and loss in real-time with a detailed trade history and HUD overlay.

## Features

- **Automatic trade detection** for Villagers and Wandering Traders
- **Real-time emerald profit/loss** using 100+ item value mappings
- **HUD overlay** with full and compact display modes, plus flash effects for profits and losses
- **Trade history screen** with profession filters, smart filters (all / profit / loss / last 10) and color-coded entries
- **Villager Memory**: persistent per-villager tracking, price comparison across villagers, glow highlights and direction arrows
- **Session management** with start/pause/resume controls and optional persistence across world closes
- **In-game config** via YACL + ModMenu (Fabric) or the mod list (NeoForge)
- **Localization** in English and German
- **Client-side only** — no server installation required

## Requirements

- **Minecraft**: 26.1-26.1.2
- **Loaders**: Fabric or NeoForge (the NeoForge jar requires Minecraft 26.1.2)
- **Java**: 25 or higher
- **Fabric only**: Fabric API (required); ModMenu + YACL (for the in-game config screen)

## Installation

1. Install [Fabric Loader](https://fabricmc.net/use/) or [NeoForge](https://neoforged.net/).
2. On Fabric, add [Fabric API](https://modrinth.com/mod/fabric-api), and optionally [ModMenu](https://modrinth.com/mod/modmenu) + [YACL](https://modrinth.com/mod/yacl) for the config screen.
3. Download the matching TradeTracker jar for your loader and drop all jars into your `mods` folder.
4. Launch Minecraft.
